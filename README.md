# Chen Lab evidence map

Target-specific post-application demo for the Ritchie Chen Lab at UCSF.

The site structures paper-reported results from Hsueh, Chen et al., *Nature* 2023 into two interactive views:

- a context-gated heart-to-brain evidence path;
- a searchable schematic of reported central-autonomic and control regions.

This is explicitly a secondary analysis of reported statistics, not a reanalysis of unavailable animal-level primary data.

Primary source: https://pmc.ncbi.nlm.nih.gov/articles/PMC9995271/
